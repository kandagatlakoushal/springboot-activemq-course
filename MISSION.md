# Mission: Spring Boot + ActiveMQ Messaging for Enterprise Interviews

## Why
Preparing for a Java backend role at S&P Global Market Intelligence (MarkIT India), where Spring Boot microservices with messaging is a core requirement. The goal is to be interview-ready — able to explain, design, and build messaging-driven Spring Boot services with confidence, and demonstrate knowledge of Spring Profiles for environment management.

## Success looks like
- Can build a multi-service Spring Boot application that communicates via ActiveMQ queues and topics
- Can explain Queue vs Topic, JMS, message durability, DLQs, and request-reply patterns in an interview
- Can set up and switch between dev/test/prod configurations using Spring Profiles
- Can design an event-driven architecture on a whiteboard using ActiveMQ as the broker
- Can write integration tests for messaging components

## Constraints
- 1 week total, 2–3 hours per day (~15–20 hours total)
- Already proficient with Spring Boot REST APIs and database integrations
- Learning through project-based, hands-on approach
- Needs Docker for running ActiveMQ locally

## Out of scope
- Apache Kafka (different paradigm, separate learning path)
- Spring Cloud Stream / Spring Integration (too abstract for this timeframe)
- Production deployment, Kubernetes, CI/CD pipelines
- Frontend development
