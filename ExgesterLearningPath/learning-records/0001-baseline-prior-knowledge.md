# Baseline: Prior Knowledge Entering the Exgester Path

The user enters this path with verified Spring Boot REST + database proficiency and JMS/AMQ fundamentals at storage strength (parent workspace: Lessons 1–7 completed, 10/10 grill on infrastructure model, JMS objects hierarchy, JmsTemplate lifecycle, queue vs topic, Artemis addresses, and basic @Profile usage). They have built working producer/consumer Spring Boot apps against a Dockerized broker.

Unverified and assumed weak until demonstrated: generics wildcards/PECS, Vavr (all of it), railway-oriented programming, the six design patterns, custom composed profile annotations, @ConfigurationProperties binding, Jackson beyond basic converters, Cucumber, JaCoCo/Checkstyle.

### Implications
- Week 1 must NOT re-teach Spring Boot basics or JMS mechanics — reference them as anchors instead.
- Session 23 (JMS in Exgester context) is a re-framing session, not an introduction.
- The zone of proximal development for Session 1 is: knows Java syntax and Spring idioms; has never deliberately designed an immutable value model. Start there.
