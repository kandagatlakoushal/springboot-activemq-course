# Spring Boot REST & Database Proficiency (Prior Knowledge)

The user has declared proficiency with Spring Boot REST APIs and database integrations (JPA/Hibernate, CRUD operations, entity mapping). This sets the floor: no need to teach Spring Boot fundamentals, dependency injection, annotations like @RestController/@Service/@Repository, or basic project setup with Spring Initializr.

This means lessons can immediately use REST controllers, services, and repositories as building blocks without explaining them — and can focus entirely on the messaging layer, Spring Profiles, and how they integrate with existing Spring Boot patterns the user already knows.
